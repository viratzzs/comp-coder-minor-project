To solve this problem, we need to find the lexicographically smallest array after performing a series of operations where we can increment an element and move it to the end of the array. The key insight is to process the array from left to right, ensuring that each element is as small as possible by comparing it with the next element and performing operations when necessary.

### Approach
1. **Problem Analysis**: The operation allows us to increment an element and move it to the end. This means that elements can be moved around the array, and we need to find the smallest possible lexicographical order after all possible operations.
2. **Intuition**: To achieve the lexicographically smallest array, we need to ensure that each element is as small as possible. This can be done by comparing each element with the next one and performing the operation if the current element is larger than the next.
3. **Algorithm**: 
   - Traverse the array from left to right.
   - For each element, if it is larger than the next element, increment it and move it to the end of the array.
   - This ensures that each element is as small as possible while maintaining the lexicographical order.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        a = list(map(int, data[idx:idx+n]))
        idx += n
        i = 0
        while i < n - 1:
            if a[i] > a[i+1]:
                # Perform the operation
                a[i] += 1
                a.append(a[i])
                del a[i]
            else:
                i += 1
        results.append(' '.join(map(str, a)))
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
- **Processing Each Test Case**: For each test case, we read the array and process it to ensure the lexicographical order.
- **Traversing the Array**: We iterate through the array from left to right. If an element is greater than the next, we increment it and move it to the end of the array.
- **Maintaining Order**: By moving elements to the end when necessary, we ensure that the array is as lexicographically small as possible.

This approach ensures that we efficiently process each element and maintain the smallest possible lexicographical order by leveraging the allowed operations. The time complexity is O(n) per test case, which is optimal given the constraints.
