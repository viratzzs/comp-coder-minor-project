For each bit b in 0..9:

   Initialize dp as [1, 0] (probability even, odd).

   For each element i in 0..n-1:

      p_i_b = (p[i] * (a[i] & (1 << b)) ) * inv_1e4 % MOD.

      new_dp[0] = dp[0] * (1 - p_i_b) + dp[1] * p_i_b.

      new_dp[1] = dp[0] * p_i_b + dp[1] * (1 - p_i_b).

      dp = new_dp.

   q_b = dp[1] (probability that sum is odd).
