To solve this problem, we need to determine Alice's score in a game where she and Bob take turns removing marbles from a set, with Alice's score calculated based on the number of marbles she has taken of each color and whether she has taken all marbles of a color.

### Approach
1. **Understanding the Game Mechanics**: Alice and Bob take turns removing marbles. Alice's score is determined by two factors:
   - She gets 1 point for each color she has taken at least one marble of.
   - She gets an additional 1 point for each color she has taken all marbles of.

2. **Key Observations**:
   - For each color with an odd number of marbles, Alice can take all marbles if she has the last turn, which depends on the parity of the number of marbles.
   - For even-numbered marbles, Alice can take half of them, so she gets 1 point for at least one but not all.
   - The score is calculated by summing points for each color based on the number of marbles and the turn order.

3. **Efficient Calculation**:
   - Count the frequency of each color.
   - For each color, if the frequency is odd, add 2 points (1 for at least one and 1 for all marbles).
   - For even frequencies, add 1 point (1 for at least one).

### Solution Code
```python
import sys
from collections import Counter

def main():
    t = int(sys.stdin.readline())
    for _ in range(t):
        n = int(sys.stdin.readline())
        c = list(map(int, sys.stdin.readline().split()))
        count = Counter(c)
        total = 0
        for color, freq in count.items():
            if freq % 2 == 1:
                total += 2
            else:
                total += 1
        print(total)

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read from standard input, with the first line containing the number of test cases.
- **Frequency Count**: Using the `Counter` from the `collections` module, we count the frequency of each color.
- **Score Calculation**: For each color, if the frequency is odd, Alice gets 2 points (1 for at least one and 1 for all marbles). If the frequency is even, she gets 1 point for at least one marble.
- **Output**: The total score for each test case is printed.

This approach efficiently calculates the score by leveraging the properties of odd and even frequencies, ensuring optimal performance within the given constraints.
