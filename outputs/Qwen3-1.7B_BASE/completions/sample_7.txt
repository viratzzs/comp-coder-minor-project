To solve this problem, we need to determine if Alice will ever meet the Red Queen while following a predetermined movement pattern. Alice starts at position (0, 0) and the Red Queen is at position (a, b). Alice's movement pattern is given by a string of directions (N, E, S, W), and she repeats this pattern infinitely.

### Approach
1. **Understanding the Movement Pattern**: Alice's movement is periodic with a period equal to the length of the movement string. This means the movement pattern repeats every `n` steps where `n` is the length of the string.
2. **Checking for Meeting Point**: To determine if Alice will meet the Red Queen, we need to check if the Red Queen's position (a, b) appears in the positions generated by the movement pattern over the first `2n` steps. This is because the pattern repeats every `n` steps, so checking up to `2n` steps covers all possible positions Alice could be in before repeating the pattern.

### Solution Code
```python
t = int(input())
for _ in range(t):
    n, a, b = map(int, input().split())
    s = input().strip()
    current_x, current_y = 0, 0
    path = set()
    for i in range(2 * n):
        if i < n:
            direction = s[i]
            if direction == 'N':
                current_y += 1
            elif direction == 'E':
                current_x += 1
            elif direction == 'S':
                current_y -= 1
            elif direction == 'W':
                current_x -= 1
            path.add((current_x, current_y))
        else:
            direction = s[i - n]
            if direction == 'N':
                current_y += 1
            elif direction == 'E':
                current_x += 1
            elif direction == 'S':
                current_y -= 1
            elif direction == 'W':
                current_x -= 1
            path.add((current_x, current_y))
    if (a, b) in path:
        print("YES")
    else:
        print("NO")
```

### Explanation
1. **Reading Input**: The number of test cases `t` is read first. For each test case, the length of the movement string `n`, the Red Queen's coordinates `(a, b)`, and the movement string `s` are read.
2. **Simulating Movement**: We simulate Alice's movement for the first `2n` steps. The first `n` steps are directly processed from the string `s`, and the next `n` steps are processed by repeating the first `n` steps of the string.
3. **Checking Position**: After simulating all possible positions up to `2n` steps, we check if the Red Queen's position `(a, b)` is in the set of positions generated. If it is, Alice will meet the Red Queen, otherwise, she will not.

This approach ensures we efficiently check all possible meeting points within the constraints, leveraging the periodic nature of Alice's movement pattern.
