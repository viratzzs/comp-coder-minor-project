To solve this problem, we need to determine the perimeter of the colored region formed by pressing an m x m square stamp multiple times on an infinite piece of paper. Each stamp is moved right by x_i and up by y_i units after each operation, and the stamp leaves an m x m colored square at its current position. The goal is to calculate the perimeter of the union of these colored squares after all operations.

### Approach
1. **Understanding the Problem**: Each stamp is moved right and up by specific distances, and each move leaves a colored square. The colored region is the union of all these squares, and the perimeter is the outer boundary of this union.
2. **Key Insight**: The perimeter of the union of squares is calculated by summing the perimeters of all individual squares and subtracting twice the length of overlapping edges between consecutive stamps. Overlapping edges are those where the distance between the centers of two consecutive stamps is exactly m (the side length of the square).
3. **Algorithm**:
   - For each test case, read the number of operations and the side length of the stamp.
   - Track the cumulative positions of the stamp after each move.
   - For each consecutive pair of moves, calculate the distance between the centers of the stamps and check if they overlap.
   - Adjust the perimeter by subtracting twice the length of overlapping edges between consecutive stamps.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n, m = int(data[idx]), int(data[idx+1])
        idx += 2
        x = []
        y = []
        for _ in range(n):
            xi = int(data[idx])
            yi = int(data[idx+1])
            x.append(xi)
            y.append(yi)
            idx += 2
        s_x = [0] * (n+1)
        s_y = [0] * (n+1)
        for i in range(1, n+1):
            s_x[i] = s_x[i-1] + x[i-1]
            s_y[i] = s_y[i-1] + y[i-1]
        sum_overlap = 0
        for i in range(n-1):
            dx = s_x[i+1] - s_x[i]
            dy = s_y[i+1] - s_y[i]
            if dx * dx + dy * dy == m * m:
                sum_overlap += 2 * (dx + dy)
        perimeter = 4 * m * n - 2 * sum_overlap
        results.append(str(perimeter))
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

- **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
- **Tracking Positions**: We maintain cumulative positions for each stamp to determine the positions after each move.
- **Overlap Calculation**: For each consecutive pair of moves, we calculate the distance between the centers of the stamps. If this distance equals m, the stamps overlap, and we adjust the perimeter by subtracting twice the length of the overlapping edges.
- **Perimeter Adjustment**: The perimeter is calculated by summing the perimeters of all individual stamps and adjusting for overlaps, ensuring we only count the outer edges of the union of squares.

This approach efficiently computes the perimeter by focusing on the overlapping edges between consecutive stamps, ensuring optimal performance even for the upper constraint limits.
