To solve this problem, we need to find the minimum cost path from the top-left cell (1,1) to the bottom-right cell (n,n) in an n x n grid. The cost of each cell (i,j) is defined as the sum of the greatest common divisors (GCD) of the row number i with a and the column number j with b. The goal is to minimize the total cost of the path by choosing the optimal sequence of moves either right or down.

### Approach
1. **Cost Calculation**: Calculate the sum of GCD values for all rows and columns in the grid.
2. **Optimal Path Distribution**: Determine the optimal distribution of down steps in rows and right steps in columns to minimize the cost.
3. **Dynamic Programming Insight**: Use dynamic programming to distribute the steps optimally, considering the GCD values for each row and column.

### Solution Code
```python
import sys
import math

def main():
    input = sys.stdin.read
    data = input().split()
    n = int(data[0])
    a = int(data[1])
    b = int(data[2])
    
    # Calculate sum of row GCDs
    sum_rows = 0
    for i in range(1, n + 1):
        sum_rows += math.gcd(i, a)
    
    # Calculate sum of column GCDs
    sum_cols = 0
    for j in range(1, n + 1):
        sum_cols += math.gcd(j, b)
    
    # Total number of down steps
    total_down = 2 * n - 2
    
    # Sort rows by their GCD with a
    sorted_rows = sorted(range(1, n + 1), key=lambda x: math.gcd(x, a))
    sum_down_rows = sorted_rows[0] * total_down
    
    # Sort columns by their GCD with b
    sorted_cols = sorted(range(1, n + 1), key=lambda x: math.gcd(x, b))
    sum_down_cols = sorted_cols[0] * total_down
    
    # Total cost is sum of row contributions + column contributions
    print(sum_rows + sum_cols + sum_down_rows + sum_down_cols)

if __name__ == "__main__":
    main()
```

### Explanation
1. **Cost Calculation**: The sum of GCD values for all rows and columns is computed to get the base cost of the grid.
2. **Optimal Distribution**: By sorting rows and columns based on their GCD values with a and b respectively, we distribute the down steps and right steps to minimize the cost contribution from each row and column.
3. **Dynamic Programming Insight**: The optimal distribution of steps is determined by sorting rows and columns based on their GCD values, ensuring that the highest GCD values are prioritized first to minimize the overall cost.

This approach efficiently computes the minimum cost path by leveraging the properties of GCD and dynamic programming, ensuring optimal performance even for large grid sizes.
