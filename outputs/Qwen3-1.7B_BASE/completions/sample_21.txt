To solve this problem, we need to determine the optimal arrangement of an array such that the score, defined as the sum of the differences between the maximum and minimum values up to each position, is maximized. The optimal arrangement involves placing the smallest element first, followed by the largest remaining elements in descending order, and finally placing the smallest remaining element at the end.

### Approach
1. **Sort the Array**: Begin by sorting the array in ascending order to facilitate the placement of the smallest elements first.
2. **Greedy Placement**: Place the smallest element first. Then, alternately place the largest and smallest remaining elements to ensure the maximum possible contribution to the score at each step.
3. **Calculate the Score**: After constructing the optimal arrangement, compute the score by iterating through the array and summing the differences between the maximum and minimum values up to each position.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        a = list(map(int, data[idx:idx+n]))
        idx += n
        a.sort()
        result = [a[0]]
        remaining = a[1:]
        while remaining:
            if len(remaining) == 1:
                result.append(remaining[0])
                break
            if len(remaining) % 2 == 0:
                result.append(remaining[-1])
                remaining = remaining[:-1]
            else:
                result.append(remaining[-1])
                remaining = remaining[:-1]
                result.append(remaining[0])
                remaining = remaining[1:]
        score = 0
        for i in range(len(result)):
            if i == 0:
                current_max = result[i]
                current_min = result[i]
            else:
                current_max = result[i]
                current_min = result[i-1] if i > 0 else result[0]
            score += current_max - current_min
        results.append(score)
    for res in results:
        print(res)

if __name__ == "__main__":
    main()
```
