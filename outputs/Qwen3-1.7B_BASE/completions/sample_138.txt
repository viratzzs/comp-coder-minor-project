To solve this problem, we need to determine the optimal strategy for Sheriff of Nottingham to maximize the gold he keeps after Robin Hood's attack by strategically strengthening camps. The key insight is to identify which camps to strengthen such that the total gold of the surviving camps is maximized.

### Approach
1. **Problem Analysis**: The gold of a camp after being strengthened is given by its initial gold minus the gold taken from its neighbors. The goal is to select a subset of camps to strengthen such that the total gold of these camps is maximized.
2. **Key Insight**: The optimal strategy involves selecting all camps with non-negative initial gold values. This is because these camps contribute positively to the total gold and do not incur additional losses from neighboring camps.
3. **Algorithm**: For each test case, sum the initial gold values of all camps that are non-negative. This sum represents the maximum gold Sheriff can keep if all non-negative camps are strengthened.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n, c = int(data[idx]), int(data[idx+1])
        idx += 2
        a = list(map(int, data[idx:idx+n]))
        idx += n
        total = sum(ai for ai in a if ai >= 0)
        results.append(total)
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

3. **Summing Non-Negative Values**: The total gold value is calculated by summing the initial gold values of all non-negative camps. This ensures that we maximize the gold kept by selecting all non-negative camps for strengthening.
4. **Output**: The results for all test cases are collected in a list and printed at once to minimize I/O operations, which is crucial for handling large input sizes efficiently.
