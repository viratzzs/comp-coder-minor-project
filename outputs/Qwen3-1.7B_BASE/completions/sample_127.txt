To solve this problem, we need to determine the minimum total latency for each possible number of servers (from 1 to n) when installing servers in the houses such that each required house is connected to at least one server with the minimum possible latency.

### Approach
1. **Problem Analysis**: Each house requiring internet must be connected to at least one server. The latency experienced by a house is the maximum latency of the cables connecting it to the server it is connected to. The goal is to minimize the total latency across all required houses for each possible number of servers (from 1 to n).

2. **Key Insights**:
   - For each required house, compute the minimum latency required to connect it to any server.
   - Sort these minimum latencies in descending order to prioritize servers with the lowest latency that cover the most required houses.

3. **Algorithm**:
   - Compute the minimum latency for each required house.
   - Sort these latencies in descending order.
   - For each number of servers (from 1 to n), sum the first `k` latencies from the sorted list. This ensures we are always selecting the most optimal servers to cover the required houses with the lowest possible latencies.

### Solution Code
```python
import sys
import heapq

def main():
    input = sys.stdin.read
    data = input().split()
    
    idx = 0
    t = int(data[idx])
    idx += 1
    
    results = []
    
    for _ in range(t):
        n = int(data[idx])
        m = int(data[idx+1])
        p = int(data[idx+2])
        idx += 3
        
        s = list(map(int, data[idx:idx+p]))
        idx += p
        
        edges = []
        for _ in range(m):
            u = int(data[idx])
            v = int(data[idx+1])
            w = int(data[idx+2])
            edges.append((u-1, v-1, w))
            idx += 3
        
        # Compute minimal max latency for each required house
        min_latency = [0] * (n)
        for i in range(p):
            s_i = s[i]
            dist = [float('inf')] * n
            dist[s_i] = 0
            heap = [(0, s_i)]
            while heap:
                d, u = heapq.heappop(heap)
                if d > dist[u]:
                    continue
                for v, w in edges:
                    if v == u:
                        continue
                    new_d = max(d, w)
                    if new_d < dist[v]:
                        dist[v] = new_d
                        heapq.heappush(heap, (new_d, v))
            min_latency[i] = dist[s_i]
        
        # Sort required houses by their min_latency in descending order
        sorted_s = sorted(s, key=lambda x: min_latency[s.index(x)], reverse=True)
        
        # For each k from 1 to n, the sum of first k min_latencies
        for k in range(1, n+1):
            total = sum(min_latency[i] for i in sorted_s[:k])
            results.append(str(total))
    
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the large constraints.
2. **Computing Minimum Latency**: For each required house, we compute the minimum latency required to connect it to any server using a modified Dijkstra's algorithm to ensure we find the shortest path in terms of maximum latency.
3. **Sorting and Summing**: The required houses are sorted by their computed minimum latency in descending order. For each possible number of servers (from 1 to n), the sum of the first `k` latencies from this sorted list gives the minimum total latency for that number of servers.

This approach ensures that we always select the most optimal servers to cover the required houses with the lowest possible latencies, thus minimizing the total latency efficiently.
