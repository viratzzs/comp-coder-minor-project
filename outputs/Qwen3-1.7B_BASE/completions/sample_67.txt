### Approach
1. **Understanding the Score Calculation**: Alice earns 1 point for each color she takes at least one marble of, and an additional 1 point for each color she takes all marbles of.
2. **Game Dynamics**: Both players alternate turns, and the optimal strategy involves taking marbles of colors that maximize Alice's score while minimizing Bob's.
3. **Key Insight**: For each color, if the number of marbles of that color is even, Alice will take all marbles of that color, earning 1 point for each color. If the number of marbles is odd, Alice will take the last marble of that color, earning 1 point for each color.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    
    idx = 0
    t = int(data[idx])
    idx += 1
    
    results = []
    
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        c = list(map(int, data[idx:idx + n]))
        idx += n
        
        even_count = 0
        odd_count = 0
        
        for color in c:
            if c.count(color) % 2 == 0:
                even_count += 1
            else:
                odd_count += 1
        
        results.append(even_count + odd_count)
    
    print("\n".join(map(str, results)))

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.

3. **Score Calculation**: For each color, if the count is even, Alice earns 1 point for each color. If the count is odd, Alice earns 1 point for each color as well. This ensures that both players' strategies are considered in the optimal play scenario.
