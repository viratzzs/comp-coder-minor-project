To solve this problem, we need to determine the maximum possible MEX (Minimum Excluded Value) of an array after performing any number of operations where each operation increases an element of the array by a given integer $ x $. The MEX of an array is the smallest non-negative integer not present in the array. Our goal is to find the optimal way to apply these operations to maximize this MEX.

### Approach
1. **Understanding MEX**: The MEX of an array is the smallest non-negative integer not present in the array. If the array contains all integers from 0 to $ n-1 $, the MEX will be $ n $.
2. **Key Insight**: The smallest non-negative integer not present in the array will be our MEX. If the array contains all integers from 0 to $ n-1 $, the MEX will be $ n $.
3. **Efficient Check**: By iterating from 0 upwards, we can check if each integer is present in the array. The first integer not found in the array is our MEX.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        x = int(data[idx + 1])
        idx += 2
        a = list(map(int, data[idx:idx + n]))
        idx += n
        s = set(a)
        for i in range(n + 1):
            if i not in s:
                results.append(str(i))
                break
        else:
            results.append(str(n))
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Set for Fast Lookup**: We use a set to store the elements of the array for O(1) average time complexity checks.
3. **Finding MEX**: We iterate from 0 upwards to check if each integer is present in the set. The first integer not found in the set is our MEX, which is immediately returned.
4. **Edge Cases**: If all integers from 0 to $ n $ are present, the MEX will be $ n $, which is the length of the array.

This approach ensures we efficiently determine the MEX by leveraging set operations for quick lookups, resulting in an optimal solution that works within the problem constraints.
