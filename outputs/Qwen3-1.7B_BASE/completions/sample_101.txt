To solve this problem, we need to count the number of non-empty good arrays of arbitrary length such that each element of the array is an integer from 1 to m. A good array is defined as one where the greatest common divisor (GCD) of the maximum values of all subarrays of length k for k from 1 to n are all distinct.

### Approach
1. **Understanding Good Arrays**: An array is good if all the GCDs of the maximum values of subarrays of different lengths are distinct.
2. **Key Insight**: The only good arrays are those where all elements are distinct. This is because if any two elements are the same, the GCDs of subarrays of different lengths can repeat, making the array non-good.
3. **Counting Permutations**: The number of good arrays of length n from the set {1, 2, ..., m} is given by the number of permutations of n distinct elements from m elements. This is calculated as m * (m-1) * ... * (m-n+1).

### Solution Code
```python
import sys
MOD = 998244353

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    
    t = int(data[0])
    idx = 1
    results = []
    
    for _ in range(t):
        m = int(data[idx])
        idx += 1
        
        # Calculate the sum of permutations P(m, n) for n from 1 to m
        total = 0
        for n in range(1, m+1):
            if n > m:
                break
            total = (total + m * (m-1) * (m-2) * ... * (m-n+1)) % MOD
        
        results.append(total)
    
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```
