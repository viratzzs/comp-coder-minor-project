To solve this problem, we need to determine the optimal distribution of work units among a team of software engineers such that the total work units are at least the required amount for a bonus project, and each engineer maximizes their own benefit based on their contribution and the total work units.

### Approach
1. **Problem Analysis**: Each engineer's benefit is determined by their contribution to the project. The goal is to distribute the work units such that the total work units meet or exceed the required amount and each engineer's contribution maximizes their benefit.
2. **Greedy Algorithm**: We use a greedy approach to iteratively increase the work units contributed by each engineer until the total work units meet or exceed the required amount. This approach ensures that each engineer contributes the maximum possible amount given the remaining work units.
3. **Edge Cases**: We handle cases where the required work units might be exceeded by the maximum possible contributions from the engineers.

### Solution Code
```python
n, k = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

c = [0] * n
total = 0

while total < k:
    found = False
    for i in range(n):
        max_c = (a[i] + b[i] - 1) // b[i]
        if c[i] < max_c:
            c[i] += 1
            total += 1
            found = True
            break
    if not found:
        break

print(' '.join(map(str, c)))
```

### Explanation
1. **Reading Input**: The input consists of the number of engineers, the required work units, the bonus amounts, and the cost per unit of work for each engineer.
2. **Initialization**: We initialize an array `c` to store the work units each engineer will contribute and a variable `total` to keep track of the cumulative work units.
3. **Iterative Increase**: We iterate through each engineer and check if their current contribution is less than their maximum possible contribution based on their bonus and cost per unit. If so, we increase their contribution and update the total work units.
4. **Termination**: The loop continues until the total work units meet or exceed the required amount, ensuring each engineer contributes optimally.

This approach ensures that we distribute the work units in a way that maximizes each engineer's benefit while meeting the required work units, providing an efficient and optimal solution.
