To solve this problem, we need to compute binomial coefficients modulo $10^9 + 7$ using a specific incorrect formula. The task is to efficiently compute these values for multiple test cases within the constraints of the problem.

### Approach
The key insight here is that the incorrect formula for computing binomial coefficients is the product of terms $(n - i)$ for $i$ from 1 to $k-1$. This approach leverages the fact that the product of these terms directly gives the binomial coefficient $C(n, k)$ when $k$ is less than $n$.

### Solution Code
```python
import sys

MOD = 10**9 + 7

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        k = int(data[idx + 1])
        idx += 2
        if k == 1:
            results.append(n - 1)
        else:
            res = 1
            for i in range(1, k):
                res = res * (n - i) % MOD
            results.append(res)
    print("\n".join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input:** The input is read in one go for efficiency, especially given the large constraints.
2. **Handling Each Test Case:** For each test case, we read the values of $n$ and $k$.
3. **Special Case for $k = 1$:** If $k$ is 1, the binomial coefficient $C(n, 1)$ is simply $n$, which we directly compute and store.
4. **Product Calculation:** For $k > 1$, we compute the product of $(n - i)$ for $i$ from 1 to $k-1$. This product is taken modulo $10^9 + 7$ to handle large numbers and prevent overflow.
5. **Output Results:** Results are collected in a list and printed at once to minimize I/O operations, which is crucial for handling the large input size efficiently.

This approach ensures that we handle each test case in linear time relative to $k$, making the solution both efficient and scalable for large inputs.
