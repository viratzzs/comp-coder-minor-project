To solve this problem, we need to determine the minimum number of operations required to make all elements of a cyclic array equal. Each operation allows us to delete an element from the array if it is adjacent to another element such that the previous element is not greater than the next element.

### Approach
1. **Understanding the Operation**: Each operation allows deleting an element if it is adjacent to another element where the previous element is not greater than the next element. This means we can delete elements in a way that maintains the order of elements where the previous element is not greater than the next.
2. **Key Insight**: The minimum number of operations required to make all elements equal is determined by the maximum frequency of any element in the array. The more frequent an element is, the fewer operations are needed to remove the other elements.
3. **Algorithm**:
   - Count the frequency of each element in the array.
   - Determine the maximum frequency.
   - The result is the total number of elements minus the maximum frequency, which gives the minimum number of operations needed to make all elements equal.

### Solution Code
```python
import sys
from collections import Counter

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        a = list(map(int, data[idx:idx + n]))
        idx += n
        freq = Counter(a)
        max_freq = max(freq.values())
        results.append(n - max_freq)
    print("\n".join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read all at once for efficiency, and then processed line by line.
- **Frequency Counting**: Using the `Counter` from the `collections` module, we count the occurrences of each element in the array.
- **Result Calculation**: The maximum frequency of any element determines the minimum number of operations needed to remove all other elements. This is because each operation can only remove one element, and the number of operations needed is the total number of elements minus the maximum frequency.

This approach ensures we efficiently determine the minimum number of operations required in linear time relative to the input size, making it optimal for the given constraints.
