To solve this problem, we need to determine the minimum number of "cool swap walks" required to sort an array in non-decreasing order, where each walk is a path from the top-left corner to the bottom-right corner of a grid, only moving right or down. The solution involves generating these paths in a way that ensures the array becomes sorted after all swaps.

### Approach
1. **Identify Sorted Array**: If the array is already sorted, no swaps are needed.
2. **Generate Swap Walks**: For each element in the sorted array, generate a path that swaps adjacent elements to move each element to its correct position. Each path consists of four steps: right (R), down (D), right (R), down (D).
3. **Output the Paths**: For each test case, print the number of paths and the sequence of steps for each path.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        a = list(map(int, data[idx:idx + n]))
        idx += n
        if a == sorted(a):
            results.append("0")
            continue
        # Generate n paths, each with 4 steps: R, D, R, D
        steps = []
        for i in range(n):
            steps.append("R")
            steps.append("D")
            steps.append("R")
            steps.append("D")
        results.append("4")
        results.append("".join(steps))
    print("\n".join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Check Sorted Array**: If the array is already sorted, we immediately output "0" as no swaps are needed.
3. **Generate Paths**: For each element in the sorted array, we generate a path that moves right and down to swap adjacent elements, ensuring each element moves to its correct position.
4. **Output Results**: The results for each test case are collected and printed in the required format, ensuring the output adheres to the problem constraints.

This approach ensures that each element in the sorted array is moved to its correct position with the minimum number of swaps, leveraging the structure of the grid to minimize the number of steps required.
