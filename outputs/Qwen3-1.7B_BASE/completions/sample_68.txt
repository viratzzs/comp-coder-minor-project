To solve this problem, we need to determine the minimum number of groups into which Alice and Bob should split their fish catches such that the difference in their scores is at least a given value. Each group's score is determined by its position in the group sequence, where the first group contributes 0 points, the second group contributes 1 point, and so on.

### Approach
1. **Understanding the Score Calculation**: The score for each group is determined by its position in the group sequence. For the i-th group (starting from 1), the score is (i-1) points.
2. **Maximizing the Difference**: To ensure the difference between Alice and Bob's scores is at least k, we need to maximize the score for the groups assigned to Bob. This is achieved by distributing the fish in a way that maximizes the score for the highest possible groups.
3. **Mathematical Formulation**: The maximum score for m groups is calculated using the formula derived from the sum of points for each group. This formula is checked against the target difference to determine if it is feasible to achieve the required score difference.

### Solution Code
```python
import math

def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    t = int(data[0])
    index = 1
    results = []
    
    for _ in range(t):
        n = int(data[index])
        k = int(data[index + 1])
        index += 2
        
        m = 1
        while True:
            s = m * (m + 1) * (m - 1) // 3
            if s >= k and m * (m + 1) // 2 <= n:
                results.append(str(m))
                break
            m += 1
            if m > int(math.sqrt(2 * n)) + 1:
                break
        else:
            results.append("-1")
    
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Iterating Over Groups**: For each test case, we iterate over possible group sizes starting from 1. For each group size, we calculate the maximum possible score using the derived formula.
3. **Checking Feasibility**: For each group size, we check if the calculated maximum score meets the required difference. If it does, we immediately return the current group size as the solution.
4. **Termination Condition**: If no valid group size is found within the feasible range, we return -1 for that test case.

This approach efficiently checks each possible group size within a bounded range, ensuring we find the minimum number of groups required or determine it's impossible. The complexity is linear with respect to the number of fish and the constraints, making it suitable for large input sizes.
