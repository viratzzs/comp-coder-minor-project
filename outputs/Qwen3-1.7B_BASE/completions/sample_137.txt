The solution involves finding the shortest paths from both starting points (Marian at vertex 1 and Robin at vertex n) and evaluating all possible meeting points where both can use their horses optimally.

### Approach
1. **Graph Representation**: Use Dijkstra's algorithm to compute the shortest paths from both starting points (vertex 1 and vertex n) to all other vertices. This helps in determining the minimum time required for each vertex to be reached by both Marian and Robin without using horses.
2. **Horse Utilization**: For each vertex, compute the minimum time required to reach it using or without a horse. If a vertex has a horse, using it halve the travel time from that vertex to the destination.
3. **Meeting Time Calculation**: For each vertex, calculate the earliest time Marian and Robin can meet there by considering both possible scenarios (using or not using horses). Track the minimum time across all vertices where both can meet simultaneously.

### Solution Code
```python
import sys
import heapq

def dijkstra(n, graph, start):
    dist = [float('inf')] * (n + 1)
    dist[start] = 0
    heap = [(0, start)]
    while heap:
        current_dist, u = heapq.heappop(heap)
        if current_dist > dist[u]:
            continue
        for v, w in graph[u]:
            if dist[v] > dist[u] + w:
                dist[v] = dist[u] + w
                heapq.heappush(heap, (dist[v], v))
    return dist

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        m = int(data[idx+1])
        h = int(data[idx+2])
        idx +=3
        horses = list(map(int, data[idx:idx+h]))
        idx += h
        graph = [[] for _ in range(n+1)]
        for __ in range(m):
            u = int(data[idx])
            v = int(data[idx+1])
            w = int(data[idx+2])
            graph[u].append((v, w))
            graph[v].append((u, w))
            idx +=3
        d1 = dijkstra(n, graph, 1)
        dn = dijkstra(n, graph, n)
        min_time = float('inf')
        for v in range(1, n+1):
            if v in horses:
                time_marian = min(d1[v], d1[v] + dn[v]/2)
                time_marian += dn[v]/2
                time_robin = min(dn[v], dn[v] + d1[v]/2)
                time_robin += d1[v]/2
            else:
                time_marian = d1[v] + dn[v]/2
                time_robin = dn[v] + d1[v]/2
            if time_marian == time_robin:
                if time_marian < min_time:
                    min_time = time_marian
        if min_time != float('inf'):
            results.append(str(min_time))
        else:
            results.append('-1')
    print('\n'.join(results))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Graph Traversal**: Using Dijkstra's algorithm, we compute the shortest paths from both starting points (vertex 1 and vertex n) to all other vertices. This helps in determining the minimum travel times without considering horse usage.
2. **Horse Time Adjustment**: For each vertex, we adjust the travel time by half if a horse is available. This adjustment is crucial as it allows both Marian and Robin to potentially meet earlier by using their respective horses.
3. **Meeting Time Evaluation**: For each vertex, we evaluate the earliest time Marian and Robin can meet there by considering both possible scenarios (using or not using horses). The minimum valid meeting time across all vertices is tracked and returned as the result.

This approach efficiently computes the minimum meeting time while considering all possible horse utilization scenarios, ensuring optimal performance even for large input sizes.
