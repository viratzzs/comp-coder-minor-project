To solve this problem, we need to determine the minimum total latency for connecting all houses requiring internet to servers placed in specific houses. The latency for each house is defined as the maximum latency of the cables connecting it to the chosen server. The goal is to select a subset of servers such that this total latency is minimized for each possible number of servers from 1 to n.

### Approach
1. **Graph Representation**: Represent the village as a graph where houses are nodes and cables are edges with given latencies.
2. **Distance Calculation**: Precompute the shortest distances from each required house to all possible servers using a breadth-first search (BFS) approach.
3. **Priority Queues**: For each required house, maintain a priority queue (min-heap) of servers sorted by their distance to the required house.
4. **Greedy Selection**: Use a greedy approach to select the servers such that each required house is assigned to the closest server in the selected set, ensuring we use exactly k servers to minimize the total latency.

### Solution Code
```python
import sys
import heapq
from collections import defaultdict

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        m = int(data[idx+1])
        p = int(data[idx+2])
        idx += 3
        required = list(map(int, data[idx:idx+p]))
        idx += p
        # Build the graph
        edges = [[] for _ in range(n+1)]
        for _ in range(m):
            u = int(data[idx])
            v = int(data[idx+1])
            w = int(data[idx+2])
            idx += 3
            edges[u].append((v, w))
            edges[v].append((u, w))
        # Precompute distances from each required house to all servers
        # Using BFS for each required house
        distance = defaultdict(lambda: defaultdict(lambda: float('inf')))
        for s in required:
            dist = [float('inf')] * (n + 1)
            dist[s] = 0
            queue = [s]
            while queue:
                u = queue.pop(0)
                for v, w in edges[u]:
                    if dist[v] > dist[u] + w:
                        dist[v] = dist[u] + w
                        queue.append(v)
            for u in range(1, n+1):
                distance[s][u] = dist[u]
        # Build priority queues for each required house
        pq = []
        for s in required:
            heap = []
            for u in range(1, n+1):
                if distance[s][u] != float('inf'):
                    heapq.heappush(heap, (distance[s][u], u))
            pq.append(heap)
        selected = set()
        total = 0
        k = 0
        while k < n and pq:
            dist, u = heapq.heappop(pq)
            if u not in selected:
                selected.add(u)
                k += 1
                total += dist
        results.append(total)
    print(' '.join(map(str, results)))

if __name__ == "__main__":
    main()
```

3. **Priority Queues**: For each required house, a min-heap is used to keep track of the servers sorted by their distance to the required house. This allows efficient retrieval of the closest server for each required house.
4. **Greedy Selection**: By iteratively selecting the closest server from the priority queue, we ensure that each required house is assigned to the closest server in the selected set, minimizing the total latency. This greedy approach ensures we use exactly k servers to cover all required houses with the minimum possible maximum latency.
