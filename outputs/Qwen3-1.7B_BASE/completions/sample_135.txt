To solve this problem, we need to determine the minimum amount of gold the richest person must find so that more than half of the population becomes unhappy. An unhappy person is defined as someone whose wealth is strictly less than half the average wealth of the entire population after adding the gold to the richest person.

### Approach
1. **Input Reading and Initial Checks**: Read the number of test cases and process each test case individually. If there's only one person, it's impossible to make them unhappy, so output -1 immediately.
2. **Sum and Maximum Calculation**: For each test case, calculate the total wealth (sum) and the maximum wealth (maximum value in the array).
3. **Sorted List of Other Weights**: Extract the list of weights excluding the maximum value and sort them in non-decreasing order.
4. **Binary Search for Minimum Gold**: Use binary search to find the minimum amount of gold (x) needed such that the number of people with wealth less than half the average wealth is more than half the population. This involves checking the average wealth after adding x to the maximum value and using binary search to efficiently find the minimum x.

### Solution Code
```python
import sys
import bisect

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        a = list(map(int, data[idx:idx+n]))
        idx += n
        if n == 1:
            results.append("-1")
            continue
        S = sum(a)
        m = max(a)
        sorted_other = sorted([x for x in a if x != m])
        k = (n + 1) // 2
        if len(sorted_other) < k:
            results.append("-1")
            continue
        low = 0
        high = 10**12
        answer = -1
        while low <= high:
            mid = (low + high) // 2
            T = (S + mid) / (2 * n)
            count = bisect.bisect_left(sorted_other, T)
            if count > n / 2:
                answer = mid
                high = mid - 1
            else:
                low = mid + 1
        results.append(str(answer) if answer != -1 else "-1")
    print("\n".join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, then split into manageable parts for processing each test case.
2. **Initial Checks**: Directly handle cases with only one person, where it's impossible to make anyone unhappy.
3. **Sum and Maximum Calculation**: Compute the total wealth (sum) and the maximum wealth (maximum value) for each test case.
4. **Sorted List of Other Weights**: Exclude the maximum value from the list and sort the remaining weights to facilitate efficient range queries.
5. **Binary Search**: Use binary search to find the minimum gold (x) required. For each midpoint value of x, compute the average wealth and use binary search to count how many people have wealth less than half of this average. Adjust the search bounds based on the count to find the minimum x that satisfies the condition.

This approach ensures we efficiently narrow down the minimum amount of gold required using binary search and sorted list operations, making the solution both optimal and easy to understand.
