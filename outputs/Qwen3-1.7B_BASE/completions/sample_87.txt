### Approach
1. **Reverse Processing**: Process the array from right to left to ensure each element is minimized while keeping the elements to the right in their original positions.
2. **Greedy Strategy**: For each element starting from the rightmost position, check if it can be reduced by incrementing the next element to the left. If it can, move it to the end of the array to maintain the smallest possible value for the current position.

import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        a = list(map(int, data[idx:idx + n]))
        idx += n
        
        # Process from right to left
        i = n - 1
        while i >= 0:
            j = i - 1
            while j >= 0 and a[j] <= a[i]:
                j -= 1
            if j >= 0:
                # Move a[j] to the end
                a = a[:j] + [a[i]] + a[j+1:i] + a[i+1:]
            i -= 1
