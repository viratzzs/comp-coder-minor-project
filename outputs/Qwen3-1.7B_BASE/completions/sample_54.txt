To solve this problem, we need to determine the minimum number of colors required to ensure that for every integer time point covered by at least one segment, there exists at least one color that appears exactly once in the segments covering that point. The solution involves efficiently tracking intervals and their overlaps to determine the optimal color distribution.

### Approach
1. **Event Processing**: For each interval, create two events: one for the start of the interval and one for its end. These events help in tracking the number of overlapping intervals at each point.
2. **Line Sweep Algorithm**: Process these events in sorted order. When an interval starts, increment the count of active intervals; when it ends, decrement the count. Track the maximum number of overlapping intervals at any point.
3. **Color Assignment**: The maximum number of overlapping intervals at any point determines the minimum number of colors needed. Each group of overlapping intervals (identified by the maximum count) is assigned a unique color.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        intervals = []
        for _ in range(n):
            l = int(data[idx])
            r = int(data[idx + 1])
            intervals.append((l, r))
            idx += 2
        events = []
        for l, r in intervals:
            events.append((l, 1))
            events.append((r + 1, -1))
        events.sort(key=lambda x: (x[0], x[1]))
        current_count = 0
        max_count = 0
        for x, delta in events:
            if delta == 1:
                current_count += 1
                if current_count > max_count:
                    max_count = current_count
            else:
                current_count -= 1
        results.append(max_count)
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Event Creation**: Each interval is converted into two events: one for the start and one for the end. This helps in tracking when intervals start and end.
2. **Sorting Events**: Events are sorted such that end events come before start events at the same position. This ensures that we correctly handle the end of an interval before processing its start.
3. **Line Sweep**: As we process each event, we maintain a count of active intervals. The maximum value of this count during the sweep gives the number of overlapping intervals at any point, which determines the minimum number of colors needed.
4. **Color Assignment**: The maximum count from the line sweep is used to determine the number of colors required. Each group of intervals that overlap at the maximum count is assigned a unique color to ensure the condition is met.

This approach efficiently tracks the maximum number of overlapping intervals and ensures optimal color distribution, adhering to the problem constraints and requirements.
