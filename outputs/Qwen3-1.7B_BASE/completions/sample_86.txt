To solve this problem, we need to maximize the cost of a path from the top-left cell (1,1) to the bottom-right cell (2,n) in a matrix with two rows and n columns. The path can only move right or down, and the cost is defined as the sum of all integers in the path, including the start and end cells.

### Approach
1. **Understanding the Path**: The optimal path from (1,1) to (2,n) must consist of exactly n steps. This includes n-1 steps to the right and 1 step down.
2. **Maximizing the Sum**: The maximum cost is determined by two possible paths:
   - **Path 1**: Start at (1,1), move right to (1,n), then down to (2,n). The cost here is the sum of all elements in the first row (except the first element) plus the element at (2,n).
   - **Path 2**: Start at (1,1), move down to (2,1), then right to (2,n). The cost here is the sum of all elements in the second row (except the first element) plus the element at (2,1).
3. **Computing the Costs**: For each test case, compute both possible costs and return the maximum of these two values.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    
    idx = 0
    t = int(data[idx])
    idx += 1
    
    results = []
    
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        
        a1 = list(map(int, data[idx:idx + n]))
        idx += n
        
        a2 = list(map(int, data[idx:idx + n]))
        idx += n
        
        option1 = a1[0] + sum(a1[1:]) + a2[-1]
        option2 = a1[0] + a2[0] + sum(a2[1:])
        
        results.append(str(max(option1, option2)))
    
    print('\n'.join(results))

if __name__ == "__main__":
    main()
```

- **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
- **Processing Each Test Case**: For each test case, the matrix dimensions and values are read, and the two possible maximum costs are computed.
- **Computing Costs**: 
  - **Option 1** computes the cost of moving right first and then down.
  - **Option 2** computes the cost of moving down first and then right.
- **Result**: The maximum of the two computed costs is stored and printed for each test case.

This approach ensures we efficiently compute the optimal path cost using only a few arithmetic operations per test case, adhering to the problem constraints and ensuring optimal performance.
