To solve this problem, we need to find two integers $A$ and $B$ within a given range $[l, r]$ such that their greatest common divisor (GCD) is exactly $G$ and the absolute difference $|A - B|$ is maximized. If multiple such pairs exist, we choose the one with the smallest $A$. If no such pair exists, we output "-1 -1".

### Approach
1. **Range Analysis**: For a given range $[l, r]$ and a required GCD $G$, compute the smallest possible $A$ and the largest possible $B$ such that $A$ and $B$ are multiples of $G$.
2. **GCD Check**: Check if the GCD of the smallest $A$ and largest $B$ is exactly $G$. If it is, then the pair $(A, B)$ is valid.
3. **Adjust for Valid GCD**: If the GCD of the smallest $A$ and largest $B$ is not $G$, check the next possible value of $B$ (i.e., $B - 1$) to ensure the GCD of the new pair is exactly $G$.

### Solution Code
```python
import math
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    t = int(data[0])
    index = 1
    results = []
    for _ in range(t):
        l = int(data[index])
        r = int(data[index + 1])
        G = int(data[index + 2])
        index += 3
        
        a_min = (l + G - 1) // G
        b_max = r // G
        if a_min > b_max:
            results.append("-1 -1")
            continue
        
        if math.gcd(a_min, b_max) == 1:
            results.append(f"{a_min} {b_max}")
        else:
            if math.gcd(a_min, b_max - 1) == 1:
                results.append(f"{a_min} {b_max - 1}")
            else:
                results.append("-1 -1")
    
    print("\n".join(results))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Range Calculation**: The smallest possible value $a_{\text{min}}$ and largest possible value $b_{\text{max}}$ are calculated using integer division and ceiling functions.
3. **GCD Check**: The GCD of the smallest $a_{\text{min}}$ and largest $b_{\text{max}}$ is checked. If it matches exactly $G$, the pair is valid.
4. **Adjustment for Valid GCD**: If the GCD does not match, the next possible value $b_{\text{max}} - 1$ is checked to ensure the GCD of the new pair is exactly $G$. If valid, the pair is returned; otherwise, "-1 -1" is returned.

This approach ensures that we efficiently find the maximum possible difference while maintaining the required GCD constraint, adhering to the problem constraints and optimizing both time and space complexity.
