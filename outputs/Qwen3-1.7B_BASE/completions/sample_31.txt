To solve this problem, we need to determine the number of different deterministic max-heaps produced by applying the given operation exactly `k` times on a perfect binary tree with size `2^n - 1`. The solution involves dynamic programming to efficiently count valid sequences of node additions while ensuring the resulting heap structure meets the deterministic max-heap criteria.

### Approach
1. **Dynamic Programming (DP) Setup**: We use a 2D DP array `dp[i][s]` where `i` represents the number of adds made so far and `s` represents the sum of depths of the nodes selected so far. The value `dp[i][s]` will store the number of valid ways to achieve the sum `s` with `i` adds.
2. **Precompute Powers of 2**: Since each node at depth `l` can be added in `2^l` ways, we precompute these powers modulo `p` for all depths from 0 to `n-1`.
3. **DP Transition**: For each number of adds `i` from 1 to `k`, and each possible sum `s` from 0 to `k`, we update `dp[i][s]` by considering each possible depth `l` and adding valid contributions from previous states.
4. **Modulo Operations**: All operations are performed under modulo `p` to handle large numbers efficiently.

### Solution Code
```python
import sys
input = sys.stdin.read

def main():
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    
    for _ in range(t):
        n = int(data[idx])
        k = int(data[idx+1])
        p = int(data[idx+2])
        idx += 3
        
        pow2 = [pow(2, i, p) for i in range(n)]
        prev = [0] * (k + 1)
        prev[0] = 1
        
        for i in range(1, k + 1):
            curr = [0] * (k + 1)
            for s in range(k + 1):
                if s < 0:
                    continue
                for l in range(n):
                    if s - l >= 0:
                        curr[s] = (curr[s] + prev[s - l] * pow2[l]) % p
            prev = curr
        
        results.append(prev[k] % p)
    
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()
```

4. **DP Transitions**: For each number of adds `i` and each possible sum `s`, we update the DP array by considering each possible depth `l` and accumulating valid contributions.
5. **Modulo Operations**: All operations are performed modulo `p` to ensure the results fit within standard integer limits and handle large values efficiently.
