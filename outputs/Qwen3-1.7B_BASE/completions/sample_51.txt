### Approach
1. **Input Reading**: Read the number of test cases and the respective column configurations for each test case.
2. **Sorting Columns**: For each test case, sort the columns in non-decreasing order.
3. **Adjusting Pairs**: Count the number of adjacent pairs in the sorted list that have a difference greater than 1. Each such pair requires exactly one move to adjust the order.
4. **Output**: Print the count of such pairs as the number of moves required to sort the columns.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        a = list(map(int, data[idx:idx+n]))
        idx += n
        a.sort()
        res = 0
        for i in range(n-1):
            if a[i] != a[i+1]:
                res += 1
        results.append(res)
    print("\n".join(map(str, results)))

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Sorting**: Each column configuration is sorted to ensure non-decreasing order.

4. **Output**: The results for each test case are printed in the required format, ensuring minimal output and efficient processing.
