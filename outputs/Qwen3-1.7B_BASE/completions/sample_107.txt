To solve this problem, we need to determine if a given string can be formed by writing the rows of a square beautiful binary matrix. A beautiful matrix is defined as having 1s on its edges and 0s inside. Each row of the matrix must start and end with 1, and the elements in between must be 0s.

### Approach
1. **Check Perfect Square**: The length of the string must be a perfect square to form a square matrix. If not, immediately return "No".
2. **Row Validation**: For each row in the string, check if it starts and ends with '1' and that all elements in between are '0'. If any row fails this check, return "No".

### Solution Code
```python
import math
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        s = data[idx]
        idx += 1
        r = int(math.isqrt(n))
        if r * r != n:
            results.append("No")
            continue
        valid = True
        for i in range(r):
            start = i * r
            end = start + r
            row = s[start:end]
            if row[0] != '1' or row[-1] != '1':
                valid = False
                break
        results.append("Yes" if valid else "No")
    print("\n".join(results))

if __name__ == "__main__":
    main()
```

1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Perfect Square Check**: We check if the length of the string is a perfect square. If not, we immediately determine the result as "No".
3. **Row Validation**: For each row in the string, we check if it starts and ends with '1' and if all elements in between are '0'. If any row fails this check, the result for that test case is "No".
4. **Output Results**: After processing all test cases, the results are printed in the required format.

This approach ensures that we efficiently validate each row of the matrix while adhering to the constraints, providing the correct result for each test case in optimal time.
