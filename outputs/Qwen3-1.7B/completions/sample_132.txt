To solve this problem, we need to determine the number of days Alyona is happy, which means that after each day, the assembled part of the puzzle is complete. The key insight is that each day adds a new layer around the central piece, and the total number of pieces assembled by the end of each day must be checked against the total number of pieces in the puzzle.

### Approach
1. **Understanding Layers**: Each day after the first day adds a new layer around the central piece. The number of pieces added on each day is given as a list.
2. **Total Pieces**: The total number of pieces assembled by the end of the last day is the sum of all pieces added each day.
3. **Check Completion**: For each day, check if the cumulative sum of pieces added up to that day equals the total number of pieces. If it does, Alyona is happy on that day.

### Solution Code
```python
import sys

def main():
    input = sys.stdin.read
    data = input().split()
    idx = 0
    t = int(data[idx])
    idx += 1
    results = []
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        a = list(map(int, data[idx:idx + n]))
        idx += n
        total = sum(a)
        current_sum = 0
        count = 0
        for i in range(n):
            current_sum += a[i]
            if current_sum == total:
                count += 1
        results.append(str(count))
    print('\n'.join(results))

if __name__ == '__main__':
    main()
```

### Explanation
1. **Reading Input**: The input is read all at once and split into a list for easier processing.
2. **Processing Each Test Case**: For each test case, we read the number of days and the list of pieces added each day.
3. **Total Pieces Calculation**: The total number of pieces is the sum of all pieces added over the days.
4. **Cumulative Check**: For each day, we keep a running total of the pieces added. If this total equals the total number of pieces, we increment the count of happy days.
5. **Output**: The results for each test case are collected and printed at once to minimize I/O operations.

This approach ensures that we efficiently check each day's contribution to the total and determine if the puzzle is complete, adhering to the constraints of memory and time limits.
