To solve this problem, we need to determine the number of milk satisfaction days for Little John, where he drinks exactly `m` pints of milk each day if possible, up to a maximum of `m` pints. The milk is fresh for `k` days, and each day, he drinks from the freshest available milk first.

### Approach
1. **Input Reading**: Read the number of test cases and for each test case, read the number of entries, maximum pints `m`, and the freshness period `k`. Then read the entries of milk acquisition.
2. **Prefix Sum Array**: Construct a prefix sum array to efficiently calculate the sum of milk available for any given day.
3. **Binary Search**: For each day, determine the range of entries that are available using binary search to find the start and end indices of the available milk entries.
4. **Sum Calculation**: For each day, compute the sum of milk available and check if it meets the requirement of `m` pints to count as a satisfaction day.

            # Using binary search
