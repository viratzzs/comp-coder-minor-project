2. **Key Insight**: The optimal strategy involves considering two main scenarios:
   - Building both strings directly without using any copy operations.
   - Using a copy operation once to transfer part of the content from one screen to another, which can save some operations.
3. **Optimal Steps Calculation**: The minimum number of operations can be determined by considering the sum of the lengths of both strings and adjusting for potential copy operations. If the strings have a common prefix, the copy operation can be used to save steps.

q = int(input())
