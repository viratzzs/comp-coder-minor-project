To solve this problem, we need to determine the minimum amount of gold the richest person must find to make more than half of the population unhappy. The key is to analyze the wealth distribution and adjust the richest person's wealth to meet the criteria.

### Approach
1. **Understanding Unhappiness**: A person is unhappy if their wealth is strictly less than half of the average wealth. This can be calculated as the total sum of wealth divided by the number of people, and half of that average.
2. **Initial Check**: If the current number of unhappy people is already more than half of the population, no additional gold is needed.
3. **Adjusting the RIChest Person's Wealth**: If the current number of unhappy people is not enough, we need to find the minimum amount of gold (x) to be added to the richest person's wealth such that more than half of the population becomes unhappy.
4. **Threshold Calculation**: Calculate the threshold value which is half of the average wealth.
5. **Count Unhappy People**: Count how many people have wealth less than the threshold.
6. **Determine Required Adjustments**: Based on the current count of unhappy people and the threshold, determine the minimum x needed to adjust the richest person's wealth to ensure more than half of the population becomes unhappy.

            # So, we need original_C - 1 + (1 if (max_val + x) < threshold else 0) > required_new_C
            # => (max_val + x) < threshold must be >= (required_new_C - original_C + 1)
            required = required_new_C - original_C + 1
            if required <= 0:
                results.append(-1)
            else:
                # x must be such that max_val + x < threshold
                # x_min is the minimal x where max_val + x < threshold
                # since max_val < threshold, x can be 0
                # but we need to check if adding x makes the new_C >= required_new_C
                # new_C = original_C - 1 + 1 = original_C
                # which is original_C >= required_new_C?
                # No, because original_C <= required_new_C
                # So, we need to find x such that (max_val + x) < threshold
                # and original_C - 1 + 1 > required_new_C
                # which is original_C > required_new_C
                # but original_C is <= required_new_C
                # So, this is not possible
                # Wait, no. required_new_C is (n + 1) // 2
                # original_C is <= required_new_C
                # So, new_C is original_C - 1 + (1 if ... )
                # So, if original_C - 1 + 1 = original_C > required_new_C?
                # No, because original_C <= required_new_C
                # So, this is not possible
                # So, no solution
                results.append(-1)
        else:
            # max_val >= threshold
            required = required_new_C - original_C
            if required <= 0:
                results.append(0)
            else:
                # need (max_val + x) < threshold
                # but max_val >= threshold, so max_val + x >= threshold
                # so (max_val + x) < threshold is false
                # new_C = original_C + 0 = original_C
                # which is <= required_new_C
                # so no solution
                results.append(-1)
    print('\n'.join(map(str, results)))

if __name__ == "__main__":
    main()

### Explanation
1. **Reading Input**: The input is read in one go for efficiency, especially given the constraints.
2. **Threshold Calculation**: The threshold is calculated as half of the average wealth.
3. **Unhappy Count**: We count how many people have wealth less than the threshold.
4. **Initial Check**: If the current count of unhappy people is already sufficient, we immediately return 0.
5. **Adjustment Calculation**: For the richest person, we check if adding x to their wealth can make more than half of the population unhappy. If not, return -1.

This approach ensures that we efficiently determine the minimum amount of gold needed or determine it's impossible to achieve the required condition.
